# Glossary — Traditional Chinese (zh-Hant, Taiwan conventions)

Terms chosen for the machine translation of the Auditioner UI (`ios/l10n/zh-Hant.json`).
Use them consistently. Address the user as 你; full-width punctuation; Taiwan vocabulary
(設定, 取消, 完成, 刪除, 分享, 資料, 檔案, 影片). Work titles and Italian score markings
stay in the original language. Never translate: Auditioner, Tutti, YouTube, Apple Music,
IMSLP, AirTurn, Apple Pencil, Supabase, homr, PDF, MusicXML, A = 440/442.

## Word-order keys

- `lists.phrase.allChairs` → `%1$@%2$@` (instrument + 清單, e.g. 大提琴清單).
- `lists.phrase.chair` → `%2$@%1$@%3$@` (instrument + position + 清單, e.g. 大提琴聲部團員清單).
- `, all chairs` → `，含所有職位`; years suffix ` (%@)` → `（%@）`, so an evidence line reads
  「我們收集到的 9 份大提琴聲部團員清單中，有 7 份列出此片段，含所有職位（2022–2026）」.
